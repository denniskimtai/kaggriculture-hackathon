# kaggriculture-hackathon

An autonomous farming agent built for **Kaggriculture**, Kaggle's turn-based farm management competition — part of a broader hackathon where AI agents compete head-to-head on a live ladder.

## Purpose

This repo houses the decision-making agent that runs a virtual farm for 30 in-game days (720 turns), competing against other participants' agents. The agent is responsible for:

- Planting, watering, fertilizing, and harvesting crops
- Buying, feeding, and caring for animals (eggs, milk, wool)
- Managing fertilizer to boost yields
- Expanding the farm by buying neighboring land
- Trading on a dynamic market that reacts to sales and demand

The goal is to end each match with the highest profit, climbing the competition's live skill-rating ladder.
